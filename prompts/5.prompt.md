지금까지 만든 앱의 스타일을 다듬고 마무리해줘.

1. 반응형: 데스크톱 화면을 기본으로 하되, 모바일 너비(예: 480px 이하)에서도
   입력 영역과 필터 탭, 목록이 깨지지 않고 자연스럽게 배치되도록 CSS 조정
2. 완료된 할 일은 목록 하단으로 자동 정렬되도록 처리 (선택 적용)
3. 카테고리별 색상 태그를 시각적으로 명확히 구분되게 다듬기
4. 빈 상태 처리: 할 일이 하나도 없거나 필터 결과가 없을 때
   "할 일이 없습니다" 같은 안내 문구 표시
5. 키보드 접근성 점검: 입력창에서 Enter로 추가, 체크박스는 Tab으로 이동 가능한지 확인
6. 전체 코드를 한 번 검토해서 중복 로직이나 불필요한 코드를 정리

마지막으로 전체 기능(추가/수정/삭제/완료/필터/진행률/새로고침 유지)이
PRD 요구사항과 일치하는지 체크리스트 형태로 정리해줘.
