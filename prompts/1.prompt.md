순수 HTML/CSS/JavaScript로 할 일 관리 앱의 기본 뼈대를 만들어줘.
프레임워크나 빌드 도구는 사용하지 마.

파일 구성:

- index.html
- style.css
- app.js

index.html에 다음 영역을 포함한 레이아웃을 만들어줘:

1. 헤더: 앱 제목 + 진행률 표시 영역(텍스트와 프로그레스 바)
2. 입력 영역: 할 일 제목 입력창, 카테고리 선택(업무/개인/공부), 추가 버튼
3. 필터 영역: 전체/업무/개인/공부 탭 버튼
4. 할 일 목록을 렌더링할 빈 컨테이너(예: <ul id="todo-list">)

이 단계에서는 정적인 마크업과 기본 CSS 레이아웃만 잡고,
자바스크립트 로직(추가/삭제/저장 등)은 아직 구현하지 마.
카테고리별로 색상을 다르게 쓸 수 있도록 CSS 클래스 구조만 미리 잡아줘.
