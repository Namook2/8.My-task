app.js에 할 일 데이터를 다루는 핵심 로직을 구현해줘.

데이터 모델은 다음 구조를 따라줘:
{
id: string,
title: string,
category: "업무" | "개인" | "공부",
completed: boolean,
createdAt: string (ISO 8601)
}

구현할 기능:

1. 할 일 추가: 입력창에 제목을 쓰고 카테고리를 선택한 뒤 추가 버튼(또는 Enter 키)으로 목록에 새 항목 생성
2. 할 일 목록 렌더링: 배열 상태를 기반으로 목록 DOM을 다시 그리는 함수
3. 완료 체크: 각 항목의 체크박스 클릭 시 completed 값을 토글하고, 완료된 항목은 취소선 등으로 시각적으로 구분
4. 수정: 항목 제목을 클릭하거나 수정 버튼을 눌러 인라인으로 제목을 편집
5. 삭제: 각 항목의 삭제 버튼 클릭 시 목록에서 제거

이 단계에서는 아직 localStorage 저장은 구현하지 말고,
메모리상의 배열 상태만으로 정상 동작하게 만들어줘.
제목이 빈 값이면 추가되지 않도록 간단한 유효성 검사도 넣어줘.
